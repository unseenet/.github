# Contributing to Unseenet

Ideas, criticism and code are welcome, in any of the Unseenet repositories.

- **Protocol changes** go through the UN-RFC process in
  [unseenet/unseenet](https://github.com/unseenet/unseenet/blob/main/rfc/un-rfc-0000.md):
  an issue first, then a draft.
- **Code and docs**: an issue first for anything larger than a fix, then a
  pull request that refers to it. A change users, operators or implementers
  will notice gets a line under `## [Unreleased]` in `CHANGELOG.md`.
- **Where things go**: the core, the node and the CLI in `unseenet`; each
  client and service in its own repository; how the repositories fit together
  is in [CONVENTIONS.md](https://github.com/unseenet/.github/blob/main/CONVENTIONS.md).
- **Docs** of what a repository holds live in its own `docs/`; the site
  [unseenet.org](https://unseenet.org) gathers them.

Pre-alpha: nothing is stable, and nothing has had a security review yet.
