# Security

Unseenet is meant to protect people who may be in danger, so weaknesses
matter more than usual. Thank you for looking.

**Please do not open a public issue.** Report it privately with
*Security → Report a vulnerability* in the repository it concerns, or, if
you are unsure where it belongs, in
[unseenet/unseenet](https://github.com/unseenet/unseenet/security/advisories/new).
Only the maintainers can read it.

Which versions get fixes, and what counts as a security problem, is in the
[core's SECURITY.md](https://github.com/unseenet/unseenet/blob/main/SECURITY.md).
